## 在飞牛音乐扩展中使用方法

1. 登录飞牛 NAS，打开插件 WebUI 后台（端口默认 `5678`）；
2. 进入左侧菜单 **「音乐源」** -> 选中 **「洛雪音乐」**；
3. 将上述 **直链订阅地址** 粘贴到「自定义源脚本地址」输入框中，或者直接点击「上传文件」上传本目录中的 `.js` 脚本；
4. 点击 **「测试并保存」**，确保状态显示正常即可！
